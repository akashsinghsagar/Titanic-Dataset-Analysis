# Titanic EDA - Akash Singh Sagar

## Overview
This project performs **Exploratory Data Analysis (EDA)** on the Titanic dataset to uncover patterns and factors that influenced passenger survival. The analysis includes data cleaning, handling missing values, visualization, and insights using Python, Pandas, Matplotlib, and Seaborn.

The project demonstrates how **data analysis techniques** can help understand real-world datasets and prepare data for predictive modeling.

---

## Features
- **Data Cleaning:** Handling missing values (`.isnull()`, `.fillna()`, `.dropna()`)  
- **Exploratory Analysis:** Summary statistics using `.describe()` and `.groupby()`  
- **Visualization:**  
  - Countplots, barplots, heatmaps, and histograms  
  - Visual analysis of survival by class, gender, and age  
- **Insights:** Discover trends like which passenger classes or genders had higher survival rates  
- **Ready for ML:** Cleaned dataset can be used for building predictive models

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/akashsinghsagar/Titanic-EDA.git
cd Titanic-EDA
````

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Notebook

Open the Jupyter notebook in VS Code:

```bash
jupyter notebook notebooks/Titanic_EDA.ipynb
```
