```markdown
## 📖 Overview
This project performs **Exploratory Data Analysis (EDA)** on the **Titanic dataset** to uncover patterns and factors that influenced passenger survival.  

- **Dataset Source:** CalmCode Titanic CSV ([Download Link](https://calmcode.io/static/data/titanic.csv))  
- **Tools:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook  

The analysis includes **data cleaning, missing value handling, visualization**, and **insights** into survival patterns.  
This project demonstrates how **real-world data can be analyzed** and prepared for predictive modeling.  

---

## ✨ Features
- 🧹 **Data Cleaning:** Handle missing values with `.isnull()`, `.fillna()`, and `.dropna()`  
- 📊 **Exploratory Analysis:** Summary statistics with `.describe()` and `.groupby()`  
- 📈 **Visualizations:**  
  - Countplots, barplots, heatmaps, and histograms  
  - Survival analysis by **gender**, **class**, **age**, and **embarked port**  
- 💡 **Insights:** Understand trends such as which passenger classes or genders had higher survival rates  
- 🤖 **Ready for ML:** Cleaned dataset can be used for predictive modeling
```

````
## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/akashsinghsagar/Titanic-EDA.git
cd Titanic-EDA
````

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run Notebook

Open the Jupyter notebook in VS Code:

